# Paper result data

This directory aggregates the local result sets used by the current paper.
The original directory names are retained under `source_archives/` so that the
experiment revision and run timestamp remain traceable.

| Directory | Paper use |
|---|---|
| `source_archives/fp32_all_df1eb08_20260717/` | rocSOLVER and DB-POTRF scaling, Cholesky profiles, large-GETRF profiles, and the original FP32 correctness data |
| `source_archives/paper_lu_final_6098e38/` | final DB-GETRF scaling, LU endpoint control, LU accuracy, ablation profiles, and the \(n=65536\) outer-width profile |
| `source_archives/paper_cholesky_coupling_kbsyrk_nomtile_6098e38/` | final Cholesky endpoint-coupling comparison |
| `source_archives/paper_coupled_threeway_paired_6098e38/` | LU coupled-small comparison used with the final LU endpoint-control data |
| `source_archives/recursive_potrf_e2e_6098e38_20260724T113800/` | recursive POTRF end-to-end scaling baseline |
| `source_archives/accuracy_e2e_nomgemm_6098e38_20260727T153027Z/` | final POTRF accuracy sweep and the added \(n=32768\) LU accuracy point |
| `source_archives/rocsolver_n49152_probe_6098e38_20260727T145925Z/` | rocSOLVER \(n=49152\) failure diagnosis |

The pre-existing `accuracy_*`, `downloads/`, and `archives/` entries retain the
earlier audited accuracy and block-collapse artifacts. In particular,
`accuracy_final_policy_f1df006_20260718T042059Z/targeted_N40960/` supplies the
targeted \(n=40960\) accuracy record cited by the result analysis.

Derived figures are not raw data. They are regenerated by the plotting scripts
under `paper/` from the archived CSV files.

Only the four paper-facing subsets under
`fp32_all_df1eb08_20260717/fp32/paper_final/` are included; unrelated GEMM
tuning and compiler-intermediate files from that server archive are omitted.
